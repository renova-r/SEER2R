# SEER2R

Reads and writes SEER*Stat data files (a .dic dictionary plus a text data file) as R data frames.

Compatibility updates by Renova.

Version 1.0.9001 adds an `Authors@R` field equivalent to the existing author and maintainer and gives `Author` the matching roles (metadata only). No R code, data or help page was changed.

## Install

Install this release from its GitHub tag:

```r
install.packages("remotes")
remotes::install_github("renova-r/SEER2R@renova-1.0.9001")
```
